Integrations & Data Storage
📈
InfluxDB v2
Time-series database for all test metrics. Written in real-time by K6 virtual users during test execution via HTTP POST (in-band). Also receives aggregated post-run summary points from the backend.
requestsRaw virtualUsers testStartEnd k6_http_*
📊
Grafana
Real-time and historical dashboards sourced from InfluxDB. Embedded directly in the PerfOps UI via a backend proxy. Panels update live during test execution — no separate login required.
p50 / p95 / p99 RPS Error Rate VU Ramp $runId Filter
🗄️
PostgreSQL · Local Storage
Primary relational data store. Holds all platform state including users, test specs, executions, agents, schedules, and notifications. Managed via Prisma ORM with full migration support.
